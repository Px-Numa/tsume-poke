# 詰めポケ Ver2

2026-11-13 作成。Ver1.1（`tsumepoke/v1_1/`）に、問題を作るルールを選ぶ仕組みを足した版になっている。初期のルールはポケモンチャンピオンズにした。
対戦の計算、ソルバ、生成の手順、代理指標は Ver1.1 と同じなので、決めたことは `tsumepoke/v1/README.md` と `tsumepoke/v1_1/README.md` を見る。
ルールを第9世代にして Ver1.1 の改善を切った状態（初期設定）では、Ver1 と同じ問題ができる。これを確かめてあるので、「ルールだけを変えた」条件もこの版で作れる。

## ルール（`rules.js`）

ルールは「PS のどのデータを使うか」「技の候補をどのランダムバトルの型から取るか」「PS と突き合わせるときの対戦形式」「メガシンカした姿を候補に入れるか」と、チームの組み方の決まり2つで書く。

| ID | データ | 技の候補 | ポケモン | 使える技 | メガシンカした姿 | 同じポケモン | メガシンカした姿の数 |
|---|---|---|---|---|---|---|---|
| `gen9` | PS の第9世代 | `data/random-battles/gen9/sets.json` | 335 匹 | 192 個 | 入れない | 制限なし | 制限なし |
| `champions`（初期値） | PS の `data/mods/champions` | `data/random-battles/champions/sets.json` | 217 匹（メガシンカした姿 56 匹を含む） | 114 個 | 入れる | 同じ側に1匹まで | 同じ側に1匹まで |

「同じポケモン」（`speciesClause`）は、メガシンカした姿と元の姿も同じポケモンとみなす。チャンピオンズの対戦では同じポケモンを2匹入れられず、メガシンカも1回の対戦で1匹だけなので、それに合わせた。`gen9` では2つとも切ってあり、Ver1 と同じ乱数の使い方になる。
メガシンカした姿を入れるとき（`--megas` を付けたときを含む）は、ルールの表に書いていなくても、どのルールでも同じ側に1匹までにする（`rules.js` の `currentRule`）。

技とポケモンの選び方（変化技や反動のある技を除く、型の技が2つ以上あるポケモンだけを使う）は Ver1 と同じ条件のままにした。
メガシンカした姿は「最初からメガシンカしている別のポケモン」として扱う。メガシンカする操作は扱わない。
チャンピオンズの能力値の式（PS の `data/mods/champions/scripts.ts`）は、努力値が0なら Ver1 の式と同じ値になる（HP は種族値＋75、ほかは種族値＋20）。そのため `calcStats` は変えていない。

足せるのは、第9世代と同じ仕組みのルールだけになる。特性や持ち物、世代ごとに違うダメージの式は `engine.js` で扱っていないためである。ルールを足したら、下の2つの突き合わせを通してから `verified: true` にする。`verified` が付いていないルールでは、どのスクリプトも止まる。

## 使い方

`詰めポケ/` のフォルダで実行する。どのスクリプトにも `--rule ID` と `--megas` / `--no-megas` を付けられる。問題のファイルはルールごとに分かれていて、`puzzles_<ルール>.json` になる（メガシンカの扱いを初期値から変えたときは `puzzles_champions_nomegas.json` のように印が付く）。

| コマンド | 内容 |
|---|---|
| `node tsumepoke/v2/generate.js 5 1` | チャンピオンズで5ターンまでの問題を作り、`puzzles_champions.json` に足す |
| `node tsumepoke/v2/generate.js 5 1 --rule gen9` | 第9世代で作る（Ver1 と同じ問題になる） |
| `node tsumepoke/v2/generate.js 5 1 --no-megas` | メガシンカした姿を入れずに作り、`puzzles_champions_nomegas.json` に足す |
| `node tsumepoke/v2/play.js --list` | チャンピオンズの問題の一覧を出す |
| `node tsumepoke/v2/rate.js 1` | チャンピオンズの問題を評価する。記録は `ratings_champions_1.json` に入る |
| `node tsumepoke/v2/verify_damage.js 20000 777 --rule champions` | ダメージ計算を PS と突き合わせる |
| `node tsumepoke/v2/verify_turn.js 2000 7 --rule champions` | 1ターンの処理を PS と突き合わせる |
| `node tsumepoke/v2/build_names_ja.js <CSVのフォルダ> --rule champions` | そのルールのポケモンの日本語名を `names_ja.json` に足す |
| `node tsumepoke/v2/data.js --rule champions` | 使える技とポケモンの数を出す |

`generate.js` のほかのオプション（`--attempts`、`--hit-weight`、`--dedup-line`、`--from`、`--out`）は Ver1.1 と同じ。`origin.options` には `rule` と `megas` も残る。

## 日本語名

`names_ja.json` は、ルールを変えて `build_names_ja.js` を動かすたびに名前を足していく形にした（Ver1 では毎回作り直していた）。チャンピオンズの217匹のうち99匹は Ver1 の表になかったので、Ver1 と同じ PokeAPI の CSV から足した。PokeAPI に名前がないメガシンカの姿は「メガ＋元の名前」に X、Y、Z を付けた名前にした（例：メガライチュウX、メガガブリアスZ）。メガニャオニクスはオスとメスで名前が重なるので、手で「（オス）」「（メス）」を付けた。全部で 437 匹の名前があり、目で確かめたのは15匹ほどになる。

## 動かして確かめたこと（2026-11-13）

- PS との突き合わせ（`verify_damage.js 20000 777`、`verify_turn.js 2000 7`）は、どちらのルールでも不一致が0件だった。

| ルール | ダメージ計算 | 1ターンの処理 |
|---|---|---|
| `gen9` | 20,000 通り（PS で 0 ダメージ 920 通り） | 1,974 局面（優先度と素早さが同じで比べなかった局面 26） |
| `champions` | 20,000 通り（同 887 通り） | 1,970 局面（同 30） |

  チャンピオンズのほうは PS の `[Gen 9 Champions] Custom Game` で動かした。メガシンカした姿もそのまま PS の対戦に出し、能力値とタイプが一致した。
- `generate.js 5 1 --rule gen9` は、局面、正解、迂回の数、延長の元が Ver1 の1,416問とすべて一致した（4分43秒）。
- `generate.js 5 1`（チャンピオンズ）では1,402問ができた（4分23秒）。同じ側にメガシンカした姿が2匹以上いる問題と、同じ側に同じポケモン（元の姿とメガシンカした姿を含む）がいる問題は、どちらも0問だった。2つの決まりを入れる前は、それぞれ188問と55問あった（1,367問のうち）。2つの決まりを入れたあとも、`--rule gen9` では Ver1 と同じ1,416問ができた。
- 代理指標の割合は、5ターンを除いて第9世代とほぼ同じだった。5ターンでは、チャンピオンズのほうが非短絡手0回の問題が多かった。乱数の種1つだけの比較なので、ルールの違いによるものかは分からない。

| ターン数 | 第9世代：非短絡手0回 | チャンピオンズ：非短絡手0回 | 第9世代：両方1回以上 | チャンピオンズ：両方1回以上 |
|---|---|---|---|---|
| 1 | 97% | 96% | 0% | 0% |
| 2 | 72% | 72% | 12% | 11% |
| 3 | 58% | 58% | 24% | 23% |
| 4 | 44% | 45% | 38% | 41% |
| 5 | 34% | 42% | 57% | 47% |

- `play.js 956 --answer`（チャンピオンズの4ターンの問題）で、メガシンカした姿を含む問題が日本語名で表示されることを確かめた。

- GUI は `node tsumepoke/gui/server.js 8787 --engine v2 --rule champions` で動く（`tsumepoke/gui/README.md`）。

## 気になっていること

- チャンピオンズの1,402問のうち992問（71%）に、メガシンカした姿が入っている。候補の217匹のうち56匹がメガシンカした姿で、1問に最大6匹が出てくるので、多くの問題に入る。被験者に分かりやすいかは見ていない。`--no-megas` で外した問題も作れる。
- 第9世代の問題とチャンピオンズの問題は同じ id でも別の問題になる。GUI の問題セットや評価の記録では、問題のファイルの名前もいっしょに残す。
